# External links

Every external address used by GetMyIP, in the app or in this repository.

All links are plain official addresses, with no referral, tracking or affiliate parameters.

## Used by the app to fetch data

| Address | Where | Purpose |
| --- | --- | --- |
| https://ipv4.ipleak.net/json/ and https://ipv6.ipleak.net/json/ | Home (default provider) | Public IP lookup |
| https://ipleak.net/json/{ip} | DNS leak test | Details of detected DNS servers |
| https://{session}-{label}.ipleak.net/dnsdetection/ | DNS leak test | Detecting DNS servers |
| https://ifconfig.co/json | Home (optional provider) | Public IP lookup |
| Your own echoip server | Home (optional provider) | Public IP lookup |
| https://check.torproject.org/exit-addresses | Home | Tor exit list, compared on the device |
